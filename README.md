# 💸 Controle de Despesas Pessoais (em desenvolvimento)

Este é um projeto pessoal feito com React para gerenciar minhas despesas do dia a dia.  
O objetivo principal é organizar as despesas por nome, valor e data, além de ter relatórios que facilitam a visualização dos gastos.

---

## Funcionalidades atuais

- Inserção de despesas com nome, valor e data  
- Relatório resumido por mês, mostrando a soma total das despesas daquele período  
- Relatório detalhado, com listagem das despesas daquele mês específico  
- Na visualização do relatório por mês, o usuário pode clicar em "exibir" para ver as despesas detalhadas daquele mês (mini filtro)  
- Edição das despesas diretamente no relatório detalhado
